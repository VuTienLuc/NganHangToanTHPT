b) Tính $M - N + P$.
	\loigiai{
		a) $M + N = (3x^2 + x^2) + (-2xy + 2xy) + (y^2 - 3y^2) = 4x^2 - 2y^2$. \\
b) $M - N + P = (3x^2 - 2xy + y^2) - (x^2 + 2xy - 3y^2) + (2x^2 - 4xy + 2y^2)$ \\
$= (3 - 1 + 2)x^2 + (-2 - 2 - 4)xy + (1 + 3 + 2)y^2 = 4x^2 - 8xy + 6y^2$.
	}
