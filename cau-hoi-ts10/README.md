# Ngân hàng tuyển sinh 10 – Toán TP.HCM

Mỗi file `BaiN.tex` chứa các **bài hoàn chỉnh** (đủ ý a, b, c) cho Bài N của đề 7 bài:

```latex
\begin{bt}%[TS10 1.0 1.2]%[ma:xxxxxxxx]
<đề bài>
\loigiai{ <lời giải + điểm từng ý> }
\end{bt}
```

Dòng đầu ghi mã dạng theo bảng `du-lieu/ts10_dang.json` (từ file Excel ma trận dạng 135 đề).
Thêm bài bằng menu **Tuyển sinh 10 → Prompt AI soạn Bài N… → Nhập kho (dán kết quả AI)**; mã `ma:` được tự gán khi nhập.
